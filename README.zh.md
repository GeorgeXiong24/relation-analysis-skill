# 关系分析 Skill

English | [简体中文](README.zh.md)

---

## 概述

**关系分析 Skill** 是一款基于本地运行、以保护隐私为首要目标的 AI
Skill。它读取您提供的两个文件——**关系背景文件**和**聊天记录文件**——并在您自己的设备上生成一份详尽、可操作的 Markdown 分析报告。

所有解析、推理与报告生成均在本地完成，您的个人数据不会被上传至云端。

---

## 核心功能

1. **本地文件解析与兼容**
   - 在本地读取并解析 **PDF**、**TXT**、**DOCX** 和 **CSV** 文件。
   - 支持两类必需输入：
     - 关系背景文件：描述您与对方的关系。
     - 聊天记录文件：记录您与对方的互动内容。

2. **关系背景基线分析**
   - 提取关键关系背景信息：对方的性格特点、人格特质、沟通风格、价值观、情感需求、边界以及您描述的关系目标。
   - 构建结构化基线，用于评估每一次互动。

3. **深度聊天记录分析**
   - 将聊天记录与基线进行交叉比对。
   - 从以下六个维度评估：
     - 沟通风格匹配度
     - 情绪基调一致性与恰当性
     - 误解点
     - 未被回应的需求
     - 积极连接点
     - 强化关系或造成摩擦的回应模式

4. **结构化 Markdown 报告生成**
   - 输出名为 `relationship-analysis-report.md` 的报告，包含：
     - 执行摘要
     - 关系背景基线
     - 关键回复逐项分析
     - 情绪时间线
     - 误解、未被回应的需求与积极连接点
     - 沟通模式评估
     - 当前关系阶段总结
     - 具体可行的改进建议
     - 分阶段关系推进路线图

5. **技术验证与纯本地处理**
   - 严格执行仅本地数据处理。
   - 内置质量检查清单，确保报告完整、准确，不含虚构内容。

---

## 隐私承诺

- **不上传云端：** 所有文件读取、解析与分析均在您的本地设备上完成，不会发送至任何外部 API、云服务或第三方服务器。
- **不保留数据：** 提取的内容仅用于生成报告，不会另存或持久化。

---

## 支持的文件格式

| 格式 | 本地解析方式 |
|------|--------------|
| `TXT` / `MD` | 直接文本读取；支持 UTF-8、UTF-16、GBK/GB2312 |
| `CSV` | 本地 pandas/Python 解析；自动识别时间戳、发送人、消息列 |
| `PDF` | `pdftotext`（Poppler）或 Python 库（`pdfplumber`、`PyPDF2`） |
| `DOCX` | `python-docx` 或直接提取 `word/document.xml` |

如果文件被加密、损坏或格式不受支持，Skill 会停止运行并要求您提供可读版本。

## 必需输入

1. **关系背景文件** — 您对关系的描述，包括对方的背景、性格、沟通偏好、价值观、目标以及任何已知的敏感点。
2. **聊天记录文件** — 您与对方互动的按时间顺序记录。

两个文件均为必填。调用 Skill 时请一并提供。

---

## 工作流程

Skill 通过五个步骤完成分析：

1. **解析本地文件** — 识别格式、提取文本、保持时间顺序并验证两个文件。
2. **构建关系基线** — 将关系背景整理为对方的结构化画像，并标注缺失信息。
3. **分析聊天记录** — 从六个维度将每次重要互动与基线进行比对评估。
4. **生成 Markdown 报告** — 撰写完整、结构化的 `relationship-analysis-report.md` 报告。
5. **验证输出** — 在交付结果前执行质量检查清单。

---

## 使用方法

1. 将 Skill 文件放入项目目录：

   ```text
   relationship-analysis-skill\SKILL.md
   ```

2. 提供两个必需文件，例如：

   ```text
   relationship-analysis-skill\evidence_list\context.txt
   
   relationship-analysis-skill\evidence_list\chat_history.csv
   或者
   relationship-analysis-skill\evidence_list\chat_history.txt
   ```

3. 在 AI 助手中调用 Skill 并请求关系分析，例如：

   ```text
   使用 context.txt 和 chat_history.csv 分析我的关系。
   ```

4. Skill 将生成报告：

   ```text
   relationship-analysis-skill\relationship-analysis-report.md
   ```

---

## 报告输出

生成的报告包含以下九个部分：

1. **执行摘要** — 关系阶段、三大优势、三大差距以及最关键的下一步。
2. **关系背景基线** — 结构化画像与缺失信息说明。
3. **关键回复分析** — 对您的主要回复逐项评估（合适 / 部分合适 / 不合适），并给出与基线关联的理由。
4. **情绪时间线** — 聊天过程中的情绪变化与匹配/错位节点。
5. **误解、未被回应的需求与积极连接点** — 三个带标签的子部分，附具体示例。
6. **沟通模式评估** — 强化关系与造成摩擦的行为模式。
7. **当前关系阶段总结** — 基于数据的阶段判断、优势与差距。
8. **可行建议** — 针对观察到的差距，提出具体、可执行的沟通改进方案。
9. **分阶段路线图** — 包含里程碑的进阶计划，帮助推进关系。

## 依赖项

大多数解析可使用内置工具完成。为获得最佳效果，可安装以下本地 Python 包（安装后无需联网）：

```bash
pip install pandas python-docx pdfplumber PyPDF2
```

PDF 文本提取优先推荐使用 Poppler 的 `pdftotext`。

## 验证与质量保证

报告定稿前，Skill 将检查：

- [ ] 所有解析均为本地处理。
- [ ] 两个必需文件均成功读取。
- [ ] 报告包含全部九个必需部分。
- [ ] 每项评估均引用基线或具体聊天示例。
- [ ] 无虚构内容；不确定的判断明确标注为推断。
- [ ] 报告使用正确的语言。
- [ ] 建议具体且可执行。

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 文件格式不受支持 | 转换为 PDF、TXT、DOCX 或 CSV。 |
| 文本显示乱码 | 将文件另存为 UTF-8 编码。 |
| CSV 列名无法识别 | 将列名改为 `timestamp`、`sender`、`message`，或告知 Skill 实际列名。 |
| PDF 无法读取 | 尝试 `pdftotext` 或安装 `pdfplumber`。 |
| 报告内容过于笼统 | 提供更详细的关系背景文件。 |
